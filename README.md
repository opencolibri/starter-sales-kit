# opencolibri/starter-sales-kit

Castor tasks of the sales kit: demo shops created from datasets, each on its own subdomain and channel, optionally private, with its own admin and theme (`sylius:shop:*`). The admin of the sales kit (`opencolibri/starter-sales-kit-bundle`) runs them through castor-api.

## Installation

In your Castor project:

```bash
castor composer require opencolibri/starter-sales-kit
```

Or install every Colibri Starter package at once with `opencolibri/starter`.

Read the [documentation](https://github.com/opencolibri/colibri-starter/blob/main/docs/sales-kit/index.md) for usage.
